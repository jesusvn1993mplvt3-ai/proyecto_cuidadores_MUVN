# Laboratorio Lisier - Guía Interactiva para Pacientes

Una aplicación web interactiva que ayuda a los pacientes a entender los estudios clínicos recomendados por sus médicos.

## Características

- **Interfaz intuitiva**: Navegación sencilla por órganos, padecimientos y estudios clínicos
- **Explicaciones claras**: Descripciones accesibles de cada prueba de laboratorio
- **Diseño responsivo**: Optimizado para dispositivos móviles
- **Información confiable**: Basada en datos del Laboratorio Lisier

## Tecnologías

- React 18
- Vite
- Tailwind CSS
- Lucide React (iconos)

## Instalación

```bash
# Instalar dependencias
pnpm install

# Ejecutar en desarrollo
pnpm dev

# Construir para producción
pnpm build
```

## Estructura

```
src/
├── App.jsx          # Componente principal
├── main.jsx         # Punto de entrada
└── index.css        # Estilos globales
```
